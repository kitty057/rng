Generates a random number.
Usage: rng [max]; replace [max] with whatever number you want the program to generate a random number between; if [max] is 60 then it will generate a random number between 0 and 60, excluding the semicolon.
How to publish for Linux x64: dotnet publish -c Release --self-contained true -r linux-x64
How to publish for Windows x64: dotnet publish -c Release --self-contained true -r win-x64
How to publish for MacOS Apple Silicon: dotnet publish -c Release --self-contained true -r osx-arm64
How to publish for MacOS Intel x64: dotnet publish -c Release --self-contained true -r osx-x64
